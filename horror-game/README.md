# Он рядом — хоррор-игра для телефона

Ты в тёмном доме, и за тобой охотится высокий мужчина в чёрной шляпе.
Найди 3 ключа и выберись через входную дверь, пока он тебя не поймал.

## Как запустить
Игра — это один файл `index.html` без зависимостей.
- **На телефоне:** открой `index.html` в браузере (Chrome / Safari). Удобнее всего включить GitHub Pages для репозитория и открыть ссылку `…/horror-game/`.
- **На ПК:** просто открой файл в браузере.

Играй в наушниках: шаги мужчины слышны слева или справа.

## Управление
| Телефон | ПК | Действие |
|---|---|---|
| Левая половина экрана (джойстик) | WASD / стрелки | Ходить |
| Кнопка «БЕГ» | Shift | Бежать (тратит выносливость, и он слышит) |
| Кнопка «Спрятаться» | E / пробел | Залезть в шкаф или выйти из него |

## Механики
- Дом каждый раз генерируется заново (лабиринт с комнатами и обходными путями).
- Видно только то, что освещает фонарик, а свет не проходит сквозь стены.
- Мужчина бродит по дому, идёт на звук бега и звон ключей, а если увидит тебя — гонится.
- С каждым найденным ключом он становится быстрее.
- В шкафу можно спрятаться, но если он видел, как ты туда залез, то найдёт тебя.
- Сердцебиение, мерцание фонарика, вибрация и красная виньетка подсказывают, что он рядом.
