# Он рядом — 3D-хоррор от первого лица для телефона

Ты просыпаешься на втором этаже старого двухэтажного дома (в духе Granny).
По дому ходит высокий мужчина в шляпе: он слышит шаги и скрип дверей.
Найди красный, синий и золотой ключи и открой три замка на входной двери. На это у тебя три ночи.

## Как запустить
### Android-приложение (APK)
Готовый файл: [`OnRyadom.apk`](OnRyadom.apk). Нужен Android 7.0 или новее. Играть лучше горизонтально.
1. Скачай `OnRyadom.apk` на телефон.
2. Открой его. Если Android спросит, разреши установку из этого источника.
3. Если Play Защита предупредит о неизвестном разработчике, нажми «Подробнее» → «Всё равно установить».

Пересобрать APK (Android SDK не нужен, только Java, Python с Pillow, npm и curl):
```bash
./android/build.sh
```
Ключ подписи `android/keystore.p12` создаётся при первой сборке и в git не попадает.
Сохрани его: без того же ключа новую версию не установить поверх старой.

### В браузере
Открой `index.html` (рядом должен лежать `three.min.js`). Старая 2D-версия — `classic-2d.html`.
- **На телефоне:** открой `index.html` в браузере (Chrome / Safari). Удобнее всего включить GitHub Pages для репозитория и открыть ссылку `…/horror-game/`.
- **На ПК:** просто открой файл в браузере.

Играй в наушниках: шаги мужчины слышны слева или справа.

## Управление
| Телефон | ПК | Действие |
|---|---|---|
| Левая часть экрана (джойстик) | WASD / стрелки | Ходить |
| Правая часть экрана (провести пальцем) | Мышь (клик — захват курсора) | Осмотреться |
| «БЕГ» | Shift | Бежать: тратит выносливость, и он слышит шаги |
| «ДЕЙСТВИЕ» | E / клик / пробел | Открыть дверь, взять ключ, спрятаться, открыть замки |
| 🔦 | F | Фонарик: без него тебя сложнее заметить |

## Механики
- Два этажа с лестницей: кухня, гостиная, столовая, спальни, ванная, детская, кладовка.
- Каждый раз ключи лежат в новых местах, двери открыты или закрыты случайно.
- Он патрулирует оба этажа, идёт на звук (бег, двери, звон ключей, замки), а увидев тебя — гонится.
- Прячься в шкафах и под кроватями. Если он видел, как ты прячешься, он тебя вытащит.
- С каждым найденным ключом и с каждой новой ночью он быстрее.
- Графика: Three.js, динамические тени от фонарика, процедурные текстуры, туман, мерцающие лампы.
- Звук: скрип половиц и дверей, шаги с направлением, тиканье часов, сердцебиение и скример.
- В меню можно выбрать качество графики: низкое, среднее или высокое.
