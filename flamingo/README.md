# Памятная мини-модель ракеты FP-5 «Фламинго» для 3D-печати

![Превью](preview.png)

Стилизованная модель крылатой ракеты FP-5 «Фламинго» на подставке с надписью
`FP-5 FLAMINGO` и `2025`. Длина ракеты — 120 мм, размах крыла — 58 мм,
подставка — 140 × 46 мм, общая высота ≈ 55 мм.

## Файлы (`stl/`)

| Файл | Что это | Как печатать |
|---|---|---|
| `fuselage.stl` | Фюзеляж с двигателем на пилоне | На плоском «брюхе», как лежит в файле |
| `wing.stl` | Крыло (одна деталь) | Плашмя, без поддержек |
| `tail.stl` | H-образное оперение | Плашмя, кили вверх, без поддержек |
| `stand.stl` | Подставка с надписью и штырём | Основанием вниз, без поддержек |
| `rocket_full.stl` | Ракета целиком одной деталью | Для фотополимерного принтера или FDM с поддержками |
| `flamingo_set.3mf` | Набор деталей, уже разложенный на столе | Открыть в слайсере (Cura, PrusaSlicer, Bambu Studio, Orca) |

## Рекомендуемые настройки (FDM)

- Сопло 0.4 мм, слой 0.12–0.16 мм (для мелких деталей и надписи)
- Заполнение 15–20 %, стенки 3
- PLA; ракету — розовым пластиком (как у прототипа «Фламинго»), подставку — серым или чёрным
- Надпись на подставке выпуклая (1 мм): можно сменить цвет на высоте 6 мм (M600 / «пауза» в слайсере)
- Поддержки: для деталей набора не нужны; при желании включите «только от стола» под мотогондолу

## Сборка

1. Вставьте крыло в сквозной паз в средней части фюзеляжа и отцентрируйте.
2. Вставьте оперение в паз в хвосте (кили вверх).
3. При необходимости зафиксируйте каплей суперклея.
4. Наденьте ракету отверстием в днище на штырь подставки.

Зазоры в пазах — 0.25 мм. Если сидит туго — слегка пройдитесь надфилем или
измените `FIT` в генераторе.

## Изменение модели

Модель генерируется скриптом `generate.py` (параметрически):

```bash
pip install manifold3d trimesh matplotlib numpy networkx lxml
python3 generate.py
```

В начале скрипта можно поменять масштаб (`SCALE`), текст надписей
(`TITLE`, `SUBTITLE`), размеры подставки, зазоры и т.д.
